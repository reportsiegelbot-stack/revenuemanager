Impossibile caricare dati.json

Il browser ha bloccato la lettura del file dati.json (succede spesso aprendo la pagina direttamente con un doppio click, per una restrizione di sicurezza dei browser sui file locali).

Due alternative:

  1. Avvia un piccolo server locale nella cartella dashboard/ ed apri la pagina da li':
    cd dashboard && python3 -m http.server poi vai su http://localhost:8000/dashboard.html
  2. Apri invece dashboard_standalone.html (nella stessa cartella): contiene gia' i dati incorporati e funziona con un semplice doppio click, senza bisogno di leggere nessun altro file.
